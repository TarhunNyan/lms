# Для локальной разработки

Для локальной разработки достаточно поднять только PostgreSQL
Java приложение можно запускать локально не в кнотейнере

```bash
docker compose up -d lms-postgres
```

После надо поправить ./.env и запускать приложение с dev профилем. Ниже приведены VMOptions для запуска

```
-Dspring-boot.run.profiles=dev -Dspring-boot.run.arguments=--debug
```
